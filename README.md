# deor

Paquete personal de R con funciones de apoyo para las tareas cotidianas.

## Instalación

``` r
# install.packages("remotes")
remotes::install_github("deor001/deor")
```
## Funciones

| Función | Descripción                                                                                   |
|---------|-----------------------------------------------------------------------------------------------|
| `fnc()` | Formatea números con convención chilena: punto como separador de miles y coma decimal         |
| `ils()` | Inserta línea de sección (tiene un addin RStudio)                                             |
| `ipr()` | Instala (si falta) y carga paquetes; se detiene con detalle si alguno no se puede instalar    |
| `lar()` | Carga archivos, comprimidos, hojas, tablas u objetos de RData como objetos del ambiente       |
| `nuo()` | Genera nombres únicos de objetos (antisombra y colisionador)                                  |
| `vtc()` | Crea ventanas Tk centradas en la pantalla principal, en modo texto o con widgets propios      |
